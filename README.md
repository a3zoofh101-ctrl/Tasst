# سوشيال برو — منصة بيع خدمات التواصل الاجتماعي (SMM Panel)

منصة PHP + MySQL كاملة لبيع خدمات التواصل الاجتماعي (متابعين، لايكات، مشاهدات...) بنفس أسلوب مواقع SMM Panel المعروفة، تشمل لوحة تحكم للمستخدمين ولوحة إدارة كاملة.

## المزايا

- تسجيل دخول / إنشاء حساب مع نظام إحالة (رابط إحالة + عمولة تلقائية)
- محفظة رصيد داخلية (Wallet) مع سجل حركات كامل
- شحن الرصيد عبر بوابة الدفع **Moyasar** (مدى / فيزا / ماستركارد / Apple Pay)
- إنشاء طلب فردي أو طلبات جماعية (Bulk Order)
- سجل طلبات مع فلاتر وحالة كل طلب
- قائمة خدمات وتصنيفات قابلة للتعديل من لوحة الإدارة
- نظام تذاكر دعم فني (محادثة بين المستخدم والإدارة)
- اشتراكات دورية (Subscriptions / Drip)
- سجل استرجاع (Refunds) مع موافقة/رفض من الإدارة
- نظام نقاط (Points) قابل للاستبدال برصيد
- API عام بصيغة JSON (balance / services / add / status) بنفس أسلوب أنظمة SMM القياسية
- نظام تسويق بالعمولة (Affiliate) مع نسبة عمولة قابلة للتعديل
- صفحة تحديثات/إعلانات
- لوحة إدارة كاملة: مستخدمين، خدمات، طلبات، تذاكر، مدفوعات، استرجاعات، اشتراكات، إعدادات
- تصميم داكن يدعم اللغة العربية (RTL) ومتجاوب مع الجوال
- زر تواصل واتساب عائم

## متطلبات التشغيل

- PHP 7.4 أو أحدث (يفضل PHP 8.x) مع امتداد `pdo_mysql` و `curl`
- MySQL 5.7+ أو MariaDB 10.3+
- استضافة تدعم `mod_rewrite` (اختياري) — تعمل على أي استضافة مشتركة (cPanel)

## التثبيت على استضافة مشتركة (cPanel)

1. ارفع جميع ملفات المشروع إلى مجلد `public_html` (أو المجلد الفرعي الذي تريد نشر الموقع فيه) عبر File Manager أو FTP.
2. من cPanel أنشئ قاعدة بيانات MySQL جديدة ومستخدم DB وامنحه كل الصلاحيات على القاعدة.
3. افتح ملف `config/config.php` وعدّل القيم التالية بمعلومات قاعدة بياناتك:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'اسم_القاعدة');
   define('DB_USER', 'اسم_المستخدم');
   define('DB_PASS', 'كلمة_المرور');
   ```
   (يمكن أيضاً ضبطها كمتغيرات بيئة `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`, `BASE_URL` إن كانت الاستضافة تدعم ذلك)
4. افتح الموقع من المتصفح — سيتم توجيهك تلقائياً إلى `install.php` الذي سيقوم بـ:
   - إنشاء جميع جداول قاعدة البيانات (من `database/schema.sql`)
   - إنشاء أول حساب مدير (Admin) عبر نموذج بسيط
5. بعد اكتمال التثبيت **احذف أو أعد تسمية ملف `install.php`** من السيرفر (يُنشأ تلقائياً ملف `install.lock` يمنع إعادة التثبيت لكن يفضل حذف الملف كليًا لأسباب أمنية).
6. سجّل الدخول بحساب المدير من `login.php` ثم اذهب إلى **لوحة الإدارة → الإعدادات** لضبط:
   - اسم الموقع، رقم واتساب، العملة
   - مفاتيح بوابة الدفع Moyasar (`Publishable Key` و `Secret Key`) من [dashboard.moyasar.com](https://dashboard.moyasar.com)
7. أضف/عدّل التصنيفات والخدمات من **لوحة الإدارة → الخدمات** بالأسعار التي تريدها.

## بنية المشروع

```
config/           إعدادات قاعدة البيانات والاتصال
includes/         دوال مشتركة، المصادقة، CSRF، تخطيط الصفحات، عميل Moyasar
database/         ملف schema.sql لإنشاء الجداول
assets/           CSS و JS
admin/            لوحة تحكم الإدارة الكاملة
api/v2/           واجهة برمجة التطبيقات (API) العامة للمستخدمين
*.php (الجذر)     صفحات لوحة تحكم المستخدم (الطلبات، الشحن، التذاكر...)
```

## ملاحظات مهمة

- **تنفيذ الطلبات حالياً يدوي بالكامل** من لوحة الإدارة (تحديث الحالة/العداد المبدئي/المتبقي لكل طلب). لم يتم ربط أي مزوّد SMM خارجي — يمكن إضافة ذلك لاحقاً بسهولة داخل `dashboard.php` و `bulk-order.php` و `api/v2/index.php` عند توفر مزوّد.
- **الاشتراكات الدورية**: يتم إنشاؤها من قبل المستخدم، وتنفيذها (إنشاء الطلب الفعلي عند حلول موعدها) يتم يدوياً بواسطة الإدارة من صفحة "الاشتراكات" (زر "تشغيل الآن"). لتفعيل التنفيذ التلقائي بالكامل، يمكن ربط سكربت `cron` يستدعي نفس منطق `admin/subscriptions.php` على فترات.
- **بوابة الدفع**: تم استخدام Moyasar عبر Invoice API. يتم التحقق من حالة الدفع دائماً عبر استدعاء مباشر لواجهة Moyasar (وليس فقط من معطيات الرابط) لضمان الأمان.
- غيّر بيانات حساب المدير الافتراضي وكلمة المرور فور التثبيت، واحذف `install.php` من السيرفر.

## قائمة تحقق قبل الإطلاق الفعلي (Go-Live Checklist)

1. **شهادة SSL**: فعّل HTTPS مجاناً من cPanel (AutoSSL) — بوابة Moyasar تتطلب رابط رجوع (callback) بصيغة `https://` في الوضع المباشر (live).
2. بعد تفعيل SSL، افتح `.htaccess` في جذر المشروع وفك التعليق عن سطرَي إعادة التوجيه لإجبار HTTPS على كامل الموقع.
3. **بيئة الإنتاج**: تأكد أن متغير البيئة `APP_ENV` غير مضبوط على `development` (القيمة الافتراضية `production` تُخفي أخطاء PHP عن الزوار وتسجّلها فقط في ملف الأخطاء بالسيرفر).
4. **مفاتيح Moyasar**: من لوحة الإدارة → الإعدادات، بدّل الوضع من `تجريبي` إلى `مباشر (Live)` وضع مفاتيح `pk_live_...` و `sk_live_...` الحقيقية بعد تفعيل حسابك في Moyasar.
5. غيّر كلمة مرور حساب المدير الافتراضي، واحذف `install.php` من السيرفر نهائياً (يبقى `install.lock` لمنع أي محاولة وصول له إن نسيت حذفه).
6. راجع الأسعار والحدود الدنيا/القصوى لكل خدمة من **لوحة الإدارة → الخدمات** قبل فتح الموقع للجمهور.
7. تأكد من نسخ احتياطي دوري لقاعدة البيانات من cPanel (Backup Wizard) بما أن المحفظة والطلبات بيانات مالية حساسة.
8. النظام يحتوي حماية مدمجة ضد محاولات تسجيل الدخول المتكررة (5 محاولات فاشلة تؤدي لإيقاف مؤقت 15 دقيقة لنفس البريد/الـ IP) — لا حاجة لإعداد إضافي.
