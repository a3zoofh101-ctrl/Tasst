# مسارك (Masarak)

موقع تعريفي سريع وباللغة العربية (RTL) لخدمة سداد الالتزامات المالية والمساعدة في تملك الفلل العقارية، مصمم لتحويل الزوار إلى محادثة واتساب مباشرة.

## البنية

- `index.html` — الصفحة الرئيسية (قسم واحد يضم كل المحتوى).
- `css/style.css` — التنسيقات.
- `js/main.js` — قائمة الجوال والسنة في التذييل.

لا يوجد أي أدوات بناء (build tools) — الموقع HTML/CSS/JS ثابت بالكامل، يمكن رفعه مباشرة على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel, Cloudflare Pages...).

## التشغيل محليًا

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## تعديل رقم واتساب أو النص

رابط واتساب موجود في عدة أماكن داخل `index.html` بالصيغة:

```
https://wa.me/966507576193?text=...
```

لتغيير الرقم أو نص الرسالة التلقائية، ابحث عن `wa.me` واستبدل الرقم (بصيغة دولية بدون + أو أصفار في البداية) والنص بعد `text=` (بترميز URL).
